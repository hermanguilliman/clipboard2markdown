Онлайн-конвертер HTML, Word и текста из буфера обмена в Markdown

«Скопипасти в Markdown» (md.guilliman.ru) — быстрый браузерный конвертер форматированного текста и HTML-разметки в чистый язык Markdown (CommonMark / GitHub Flavored Markdown). Просто скопируйте фрагмент статьи из браузера, документа Microsoft Word, Google Docs или Notion и нажмите Ctrl+V (Cmd+V на Mac) либо перетащите .html файл в окно редактора.

Инструмент автоматически сохраняет заголовки, таблицы, списки, ссылки, блоки кода и выделение текста, очищая мусорные стили и теги. Поддерживается настройка стиля заголовков (ATX / Setext), маркеров списков, разделителей курсива и локальная история конвертаций прямо в браузере.
